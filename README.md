# 본초담 本草談 — 한방화장품 쇼핑몰 (교육용)

Claude 에이전트가 **복사·붙여넣기 없이** 직접 만든 실습용 쇼핑몰입니다.
실제 결제·배송은 이루어지지 않는 **가상 브랜드**입니다.

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 쇼핑몰 화면 (제품, 원료 사전, 루틴, 후기, 장바구니, 주문, 문의) |
| `admin.html` | 관리자 화면 (주문 상태 변경, 제품 등록·수정, 문의·후기·회원 관리) |
| `style.css` | 두 화면이 함께 쓰는 디자인 |
| `config.js` | Supabase 연결 정보와 공용 도구 |
| `devices.js` | 오른쪽 아래 PC·태블릿·모바일 화면 보기 아이콘 |

## 데이터 창고 (Supabase: bonchodam-shop)

| 표 | 내용 | 누가 볼 수 있나 |
|---|---|---|
| products | 제품 | 누구나 (판매 중인 것만) |
| ingredients | 원료 | 누구나 |
| reviews | 후기 | 누구나 보기·쓰기 / 관리자가 숨김 처리 |
| profiles | 회원 정보 | 본인, 관리자 |
| cart_items | 장바구니 | 본인만 |
| orders, order_items | 주문 | 본인, 관리자 (상태 변경은 관리자만) |
| inquiries | 문의 | 누구나 쓰기 / 관리자만 보기 |
| newsletter | 구독 | 누구나 신청 / 관리자만 보기 |
| (사진 보관함) product-images | 제품 사진 | 누구나 보기 / 관리자만 올리기·지우기 |

- 주문 금액은 서버 함수 `place_order`가 계산하므로 화면에서 가격을 바꿔도 주문 금액은 바뀌지 않습니다.
- 지정된 관리자 이메일로 가입하면 자동으로 관리자 권한이 생깁니다.

## 제품 사진

- 관리자 화면 → 제품 관리 → 수정 → **사진 올리기**를 누르면 사진이 800×800으로 자동으로 줄어든 뒤 Supabase 사진 보관함(product-images)에 저장되고, 쇼핑몰에 바로 반영됩니다.
- `images/` 폴더에는 처음 넣은 제품 사진 6장과 모델 화보 4장이 있습니다.

## 수업 시연 포인트

1. Supabase에서 제품 가격을 바꾸고 → 쇼핑몰 새로고침 → 바로 반영
2. 관리자 화면에서 새 제품 등록 → 쇼핑몰에 즉시 등장
3. 관리자 화면에서 제품 사진 올리기 → 쇼핑몰 사진이 바로 바뀜
4. 고객이 주문 → 관리자가 '배송중'으로 변경 → 고객 '나의 주문'에 반영
